MySQL 环境配置

February 20, 20221 分钟阅读 Linner 备忘录SQL环境搭建MySQL

Ubuntu

MySQL 8 安装：

  1. 首先更新本地存储库索引：

    1sudo apt update

  2. 从 APT 存储库安装 MySQL：

    1sudo apt install MySQL-server -y

  3. 查看 MySQL 版本，验证是否安装成功：

    1mysql --version

  4. 检查 MySQL 是否正在运行：

    1systemctl status mysql.service

如果服务未运行：

1sudo systemctl start mysql

MySQL 安装完成后需要更改密码。

  1. 查看默认账户和密码：

    执行后找到 user 和 password，如：

    1sudo vim /etc/mysql/debian.cnf

    或：

    1sudo cat /etc/mysql/debian.cnf

    找到如下：

    1user     = debian-sys-maint
2password = 12E0cDBeusG6vANp

  2. 使用默认账户登录：

    然后输入默认密码：

    1mysql -udebian-sys-maint -p

    112E0cDBeusG6vANp

  3. 输入以下命令修改 root 密码：

    1ALTER USER 'root'@'localhost' identified WITH mysql_native_password BY 'your_password';

  4. 修改完成后执行：

    1FLUSH privileges;
2QUIT

  5. 最后重启 MySQL 后就可以使用 root 用户了：

    1sudo service mysql restart

    1mysql -uroot -p
